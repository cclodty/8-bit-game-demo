# Mechanic Spec — 書橋（Day 4）

## 機制目標
提供短時間「生成平台」，支援路徑創造與節奏決策。

## 規則
- 可放置點：僅限 `BridgeAnchor` 標記位置。
- 生成耗能：1 點墨能（初版最大 3 點）。
- 持續時間：`3.2s`
- 冷卻：`2.5s`
- 同時存在上限：1 座
- 失效提示：結束前 `0.6s` 閃爍

## 失敗保護
- 玩家站在橋上失效時，給 `0.2s` 容錯（Grace Drop）。
- 禁止在尖刺正上方生成（防止無解死亡）。

## 驗收案例
1. 連續兩次施放需受冷卻約束。
2. 橋失效閃爍與碰撞消失同步。
3. 超出 Anchor 範圍不可放置。
