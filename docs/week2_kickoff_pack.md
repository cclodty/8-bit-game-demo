# Week 2 Kickoff Pack

## Sprint Goal
把文檔規格轉成「可操作、可通關、可結算」最小可玩版本。

## 任務包
### 工程
- 實作 PlayerController（依 `player_controller_spec.md`）
- 建立 Input Map（依 `input_map.md`）
- 接入 State Machine（依 `player_state_machine.md`）

### 關卡
- 建立 Stage 1-1 白盒場景
- 放置 2 個 checkpoint
- 連接 Goal Trigger

### UI
- 建立 Top Bar HUD
- 建立 Chapter Complete 基本版（可跳過）

### QA
- 撰寫 Controller 手感測試單
- 撰寫 Stage 1-1 通關測試單
- 驗證 scoring_rules 三組測例

## Week 2 Exit Criteria
- 可完成一輪 2–4 分鐘通關流程
- 通關後可看到結算畫面與分數
- 無 P0 crash / soft lock
