# Stage 1-1 Blockout（Day 3）

## 關卡目標
- 教會玩家：跳躍、二段跳、衝刺、基礎機關。
- 通關目標時間：`2:30 ~ 4:00`。

## 區段切分
1. `A 區（教學）`：平緩平台 + 單一高低差
2. `B 區（節奏）`：短平台連跳 + 一次二段跳必須使用
3. `C 區（機關）`：拉桿開門 + 限時通過
4. `D 區（終點）`：安全區 + 鐘樓 Goal

## 白盒元素數量（初版）
- 固定地板平台：18
- 移動平台：3
- 可掉落平台：2
- 尖刺/危險區：5
- 重生點（Checkpoint）：2

## 失敗點設計
- 失敗後重生點距離失敗點 <= 8 秒路程。
- 不連續放置兩個高懲罰陷阱。
